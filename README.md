## 📌 Descripción del Proyecto
Aplicación desarrollada en Python que cumple con los requerimientos del Parcial de **Programación Computacional III** de la Universidad Gerardo Barrios (UGB). El sistema integra manipulación avanzada de datos mediante Pandas, una interfaz gráfica interactiva construida en PyQt5, y visualización gráfica con Matplotlib orientada a la consultoría de datos para sucursales comerciales en El Salvador.

---

## 📂 Estructura del Repositorio
* `Parcial2.py`: Código fuente principal de la aplicación gráfica y análisis de datos.
* `datos.csv`: Conjunto de datos con el inventario detallado por sucursal.
* `Informe_Consultoria.pdf`: Documento formal de consultoría con hallazgos, conclusiones y recomendaciones estratégicas.
* `requirements.txt`: Archivo de dependencias y librerías del proyecto.
* `.gitignore`: Configuración de exclusión para control de versiones en Git.
